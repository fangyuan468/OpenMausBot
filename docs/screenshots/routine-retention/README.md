# Routine retention verification

Captured with an isolated fake-engine server and the actual Settings window in headless Chrome for Testing. All displayed workspace and account information belongs to the disposable fixture.

Before images use the capability-absent path, which renders the upstream Data page without the cleanup control. After images use the new server capability with cleanup disabled. Midnight and Daylight each have 1440 by 900 and 390 by 844 captures. Simple-mode images show settings with Data unavailable. Extra images show saving, enabled, and an injected fixture save error.

Keyboard checks cover Space to enable, Enter to attempt disabling, the disabled control during saving, a failed save retaining the setting, and successful retry. The seven-day value was checked through the fixture API.
